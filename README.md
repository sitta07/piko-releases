# Piko downloads

**You type, it types.** A tiny pixel friend riding a cloud by the side of your screen.

Get the latest build from [Releases](https://github.com/sitta07/piko-releases/releases/latest):
the `.dmg` for macOS, the `-setup.exe` for Windows. Free.

The builds aren't code-signed yet.
- **macOS:** open Piko once, then **System Settings › Privacy & Security › Open Anyway**.
- **Windows:** SmartScreen → **More info › Run anyway**.

This repository only holds the builds and the update file the app checks. Questions and bug reports
are welcome as issues here.
